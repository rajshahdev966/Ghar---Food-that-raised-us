# GHAR — 64 Food Illustration Prompts + Animation Implementation Prompt

> **Purpose:** Generate a coherent set of 64 food illustrations for GHAR and then hand those SVG assets to a coding model to build the animated recipe section.

> **Core emotional rule:** The artwork is not a product photograph. It should feel like a memory of food someone made for you.

---

# 1. Master visual direction

Use the following visual language for **every** image:

> hand-painted editorial vector food illustration for GHAR — Food That Raised Us; tactile warm paper feeling; organic slightly imperfect shapes; subtle ink/brush outlines; sophisticated editorial cookbook aesthetic mixed with nostalgic children's-book warmth; homemade rather than restaurant-styled; muted earthy palette of warm cream, terracotta, turmeric, sage/olive, deep brown and charcoal, with culturally appropriate accents; soft natural shading; compact isolated composition on transparent background; approximately square; generous transparent padding; no text, letters, logos, flags or typography; no photorealism; no 3D render; no glossy app-icon aesthetic; no plastic surfaces; no excessive micro-detail; culturally respectful and specific; suitable for clean SVG conversion and web animation; keep main food, container, garnish, highlights/liquid, steam and particles visually separable.

## Asset requirements
- Prefer vector/SVG output.
- Transparent background.
- 1:1-ish composition.
- Keep generous negative space around the food.
- Separate or clearly traceable groups for main food, secondary food, garnish, liquid/highlight, steam and particles.
- Do not bake text into the image.
- Use the same lighting direction, line weight, texture and visual density across the whole set.

## Suggested filename
`country-mood-dish.svg`

Example: `india-coming-home-dal-chawal.svg`

After generation, inspect each SVG. Do not immediately ask the coding model to animate an unstructured SVG.

```html
<svg class="food-illustration" viewBox="0 0 500 500">
  <g id="food-shadow">...</g>
  <g id="main-food">...</g>
  <g id="secondary-food">...</g>
  <g id="garnish">...</g>
  <g id="highlight">...</g>
  <g id="steam">
    <path id="steam-1">...</path>
    <path id="steam-2">...</path>
  </g>
  <g id="particles">...</g>
</svg>
```

Do not animate every path. Group logically and animate only the elements that create the illusion of warmth.

# 4. Animation system

Build a reusable CSS animation library rather than 64 unique animations.

Recommended primitives:

- `steam-rise` — upward drift, slight horizontal drift, scale and fade
- `food-warmth` — extremely subtle scale/opacity breathing
- `liquid-ripple` — tiny surface movement
- `highlight-shimmer` — slow highlight translation/opacity
- `garnish-float` — 1–2px organic movement
- `soft-bounce` — very small elastic movement for mochi/bhatura
- `layer-reveal` — subtle reveal for lasagna/moussaka/baklava
- `syrup-shimmer` — slow highlight for syrup/honey
- `noodle-drift` — tiny movement of selected noodle strands
- `plate-arrival` — initial translateY/opacity/rotation entrance

Use `transform` and `opacity` whenever possible. Avoid continuous animation of layout properties such as width, height, top, left or margin.
